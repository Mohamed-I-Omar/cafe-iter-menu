# Café Iter — Digital Menu

منيو رقمي لكافيه Iter، صفحة واحدة ثابتة يفتحها العملاء بمسح QR — قابل للتعديل بالكامل من لوحة إدارة على الموبايل، والتعديلات تُحفظ في Supabase وتظهر للعملاء فورًا دون تغيير الرابط أو الـ QR.

## المحتويات
- `index.html` — الموقع (يُنشر على Vercel).
- `menu.html` — نفس الكود (المصدر المستخدم للتوليد).
- `supabase-setup.sql` — سكربت إعداد قاعدة البيانات (شغّله مرة واحدة).

## التقنية
- استضافة ثابتة على **Vercel**.
- تخزين المنيو في **Supabase** (جدول `menu`، صف JSON واحد).
- القراءة عامة للجميع؛ الحفظ محمي بكلمة سر عبر دالة `save_menu`.

## الإعداد (مرة واحدة)
1. أنشئ مشروع Supabase مجاني على https://supabase.com
2. من **SQL Editor** شغّل محتوى `supabase-setup.sql` (بعد تغيير كلمة السر).
3. من **Project Settings → API** انسخ `Project URL` و `anon public key`.
4. ضعهما في أعلى سكربت الصفحة داخل `index.html` (المتغيرات `SUPABASE_URL` و `SUPABASE_ANON`).
5. ارفع على Vercel — الموقع جاهز.

## التعديل من الموبايل
افتح الموقع وأضف `#admin` في آخر الرابط، أو اضغط على اللوجو ٥ مرات → لوحة الإدارة.
عند الحفظ لأول مرة يطلب كلمة سر الإدارة (نفس اللي في `supabase-setup.sql`).
